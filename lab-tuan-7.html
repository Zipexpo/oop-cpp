1. virtual: chọn hàm theo đối tượng thật ​

Tuần 6, gọi qua con trỏ lớp cha luôn chạy bản của lớp cha. Thêm virtual trước hàm ở lớp cha và override ở lớp con thì khác hẳn:

Thấy trên UMLViết trong file .h
+ show() : void {virtual} ở lớp chavirtual void show() const;
+ show() : void {override} ở lớp convoid show() const override;
+ ~Track() {virtual}virtual ~Track(); (mục 3)

virtual và override chỉ viết ở khai báo trong lớp. Nếu thân hàm viết riêng trong file .cpp thì dòng định nghĩa giữ nguyên như cũ, không lặp lại hai từ này.

cpp
#include <iostream>
#include <string>
using namespace std;

class Track {
protected:
    string title;
    int seconds;

public:
    Track(const string& title, int seconds) : title(title), seconds(seconds) {}

    virtual void show() const {
        cout << "[BAN GHI] " << title << " | " << seconds << " giay" << endl;
    }

    virtual int price() const { return 5000; }         // gia tai ve, tinh bang dong

    void receipt() const {                             // KHONG ao, nhung goi mot ham ao
        cout << "  Tai " << title << ": " << price() << " dong" << endl;
    }

    virtual ~Track() {}
};

class Song : public Track {
private:
    string artist;

public:
    Song(const string& title, int seconds, const string& artist)
        : Track(title, seconds), artist(artist) {}

    void show() const override {
        cout << "[BAI HAT] " << title << " | " << artist << " | " << seconds << " giay" << endl;
    }

    int price() const override { return 10000; }
};

class Podcast : public Track {
private:
    int episode;

public:
    Podcast(const string& title, int seconds, int episode)
        : Track(title, seconds), episode(episode) {}

    void show() const override {
        cout << "[PODCAST] " << title << " | Tap " << episode << " | " << seconds << " giay" << endl;
    }

    int price() const override { return 0; }
};

int main() {
    Track* ds[3];
    ds[0] = new Song("Hello Viet Nam", 263, "Pham Quynh Anh");
    ds[1] = new Podcast("Chuyen lap trinh", 1800, 12);
    ds[2] = new Track("Ban thu am", 95);

    for (int i = 0; i < 3; i++)
        ds[i]->show();                 // cung mot loi goi, ba ket qua
    for (int i = 0; i < 3; i++)
        ds[i]->receipt();

    for (int i = 0; i < 3; i++)
        delete ds[i];
    return 0;
}
text
[BAI HAT] Hello Viet Nam | Pham Quynh Anh | 263 giay
[PODCAST] Chuyen lap trinh | Tap 12 | 1800 giay
[BAN GHI] Ban thu am | 95 giay
  Tai Hello Viet Nam: 10000 dong
  Tai Chuyen lap trinh: 0 dong
  Tai Ban thu am: 5000 dong
  • Cả ba phần tử của ds đều có kiểu Track*, nhưng mỗi dòng in theo đúng đối tượng thật. Hàm virtual được chọn lúc chạy, theo đối tượng mà con trỏ đang trỏ tới.
  • receipt() không virtual, nhưng bên trong gọi price() là hàm ảo, nên giá vẫn đúng theo từng loại.

Bỏ virtual ở lớp cha (và override ở lớp con) thì quay về đúng hiện tượng của bài 6.3:

text
[BAN GHI] Hello Viet Nam | 263 giay
[BAN GHI] Chuyen lap trinh | 1800 giay
[BAN GHI] Ban thu am | 95 giay
  Tai Hello Viet Nam: 5000 dong
  Tai Chuyen lap trinh: 5000 dong
  Tai Ban thu am: 5000 dong

2. override: để g++ bắt lỗi gõ sai ​

Hàm ở lớp con phải trùng chữ ký với hàm ảo của lớp cha, kể cả chữ const. Viết void show() override { mà quên const:

text
main.cpp:34:10: error: 'void Song::show()' marked 'override', but does not override
   34 |     void show() override {
      |          ^~~~

Quên const mà cũng không có override thì chương trình vẫn biên dịch được. show() của Song lúc này là một hàm khác, không ghi đè gì cả, và g++ chỉ để lại một cảnh báo rất dễ bỏ qua:

text
main.cpp:13:18: warning: 'virtual void Track::show() const' was hidden [-Woverloaded-virtual=]
   13 |     virtual void show() const {
      |                  ^~~~
main.cpp:34:10: note:   by 'void Song::show()'
   34 |     void show() {
      |          ^~~~
text
[BAN GHI] Hello Viet Nam | 263 giay
[PODCAST] Chuyen lap trinh | Tap 12 | 1800 giay
[BAN GHI] Ban thu am | 95 giay

Bài hát lại in thành [BAN GHI]. Có override, lỗi này hiện ra ngay lúc biên dịch. Cùng thông báo marked 'override', but does not override cũng xuất hiện khi lớp cha quên virtual.

3. Destructor ảo ​

Lớp con có thể xin thêm bộ nhớ riêng, như Song dưới đây giữ lời bài hát bằng new. Muốn delete qua con trỏ lớp cha mà vẫn dọn được phần đó, destructor của lớp cha phải virtual:

cpp
#include <iostream>
#include <string>
using namespace std;

class Track {
protected:
    string title;

public:
    Track(const string& title) : title(title) {}

    virtual void show() const {
        cout << "[BAN GHI] " << title << endl;
    }

    virtual ~Track() {
        cout << "  (huy Track " << title << ")" << endl;
    }
};

class Song : public Track {
private:
    string* lyrics;                      // loi bai hat, xin bang new

public:
    Song(const string& title, const string& text) : Track(title), lyrics(new string(text)) {}

    void show() const override {
        cout << "[BAI HAT] " << title << " | " << *lyrics << endl;
    }

    ~Song() override {
        delete lyrics;
        cout << "  (huy Song " << title << ", da tra loi bai hat)" << endl;
    }
};

int main() {
    Track* a = new Song("Hello Viet Nam", "Xin chao Viet Nam...");
    Track* b = new Track("Ban thu am");
    a->show();
    b->show();

    delete a;
    delete b;
    return 0;
}
text
[BAI HAT] Hello Viet Nam | Xin chao Viet Nam...
[BAN GHI] Ban thu am
  (huy Song Hello Viet Nam, da tra loi bai hat)
  (huy Track Hello Viet Nam)
  (huy Track Ban thu am)

Destructor của lớp con chạy trước, rồi mới tới lớp cha: dọn phần riêng trước, phần chung sau.

Bỏ virtual ở ~Track() mà ~Song() vẫn còn override thì không biên dịch được:

text
main.cpp:32:5: error: 'Song::~Song()' marked 'override', but does not override
   32 |     ~Song() override {
      |     ^

Bỏ luôn override thì biên dịch được, kèm cảnh báo:

text
main.cpp: In function 'int main()':
main.cpp:44:5: warning: deleting object of polymorphic class type 'Track' which has non-virtual destructor might cause undefined behavior [-Wdelete-non-virtual-dtor]
   44 |     delete a;
      |     ^~~~~~~~
text
[BAI HAT] Hello Viet Nam | Xin chao Viet Nam...
[BAN GHI] Ban thu am
  (huy Track Hello Viet Nam)
  (huy Track Ban thu am)

Destructor của Song không chạy, nên lời bài hát xin bằng new không bao giờ được trả. Luật để nhớ: lớp nào có hàm virtual thì destructor cũng phải virtual.

4. Nạp chồng toán tử ​

Lớp Duration giữ thời lượng dạng phút và giây. Nạp chồng toán tử cho phép viết a + b, a - b, cout << a như với số:

cpp
#include <iostream>
using namespace std;

class Duration {
private:
    int minutes, seconds;                // luon giu 0 <= seconds < 60

public:
    Duration(int m, int s) : minutes(m), seconds(s) {
        minutes += seconds / 60;         // 3 phut 75 giay -> 4 phut 15 giay
        seconds %= 60;
    }

    Duration operator+(const Duration& other) const {
        return Duration(minutes + other.minutes, seconds + other.seconds);   // doi tuong MOI
    }

    int operator-(const Duration& other) const {         // chenh lech, tinh bang giay
        return (minutes * 60 + seconds) - (other.minutes * 60 + other.seconds);
    }

    friend ostream& operator<<(ostream& os, const Duration& d);
};

ostream& operator<<(ostream& os, const Duration& d) {
    os << d.minutes << ':';
    if (d.seconds < 10) os << '0';
    os << d.seconds;
    return os;
}

int main() {
    Duration a(4, 23), b(3, 45);
    Duration c = a + b;
    cout << a << " + " << b << " = " << c << endl;
    cout << "Bai dau dai hon bai sau " << (a - b) << " giay" << endl;
    cout << "Sau phep cong, a van la " << a << endl;
    return 0;
}
text
4:23 + 3:45 = 8:08
Bai dau dai hon bai sau 38 giay
Sau phep cong, a van la 4:23
  • a + b là cách viết gọn của a.operator+(b). Hàm có const và trả về một đối tượng mới, nên a giữ nguyên.
  • Kiểu trả về do bạn chọn: operator+ trả Duration, operator- trả int (số giây chênh lệch).
  • operator<< không làm hàm thành viên của Duration được, vì bên trái dấu << là cout chứ không phải một Duration. Nó là hàm ngoài lớp, được khai báo friend để đọc thuộc tính private. Nó nhận ostream& và trả lại chính os, nhờ vậy mới viết nối được cout << a << " + " << b.
  • In số 0 ở đầu khi cần: if (d.seconds < 10) os << '0';.

Quên friend. Khai báo trong lớp khi đó là một hàm thành viên. Hàm thành viên đã ngầm nhận đối tượng hiện tại làm toán hạng bên trái, cộng thêm hai tham số là thừa một (trích):

text
main.cpp:22:14: error: 'std::ostream& Duration::operator<<(std::ostream&, const Duration&)' must have exactly one argument
   22 |     ostream& operator<<(ostream& os, const Duration& d);
      |              ^~~~~~~~
main.cpp: In function 'std::ostream& operator<<(std::ostream&, const Duration&)':
main.cpp:26:13: error: 'int Duration::minutes' is private within this context
   26 |     os << d.minutes << ':';

Trả về void. cout << a khi đó không trả lại gì để nối tiếp << " + " (trích):

text
main.cpp: In function 'int main()':
main.cpp:34:15: error: invalid operands of types 'void' and 'const char [4]' to binary 'operator<<'
   34 |     cout << a << " + " << b << " = " << c << endl;
      |     ~~~~~~~~~ ^~ ~~~~~
      |          |       |
      |          void    const char [4]

Sửa luôn đối tượng bên trái. Bỏ const rồi cộng thẳng vào thuộc tính:

cpp
    Duration operator+(const Duration& other) {           // SAI: sua chinh doi tuong ben trai
        minutes += other.minutes;
        seconds += other.seconds;
        minutes += seconds / 60;
        seconds %= 60;
        return *this;
    }
text
8:08 + 3:45 = 8:08
Bai dau dai hon bai sau 263 giay
Sau phep cong, a van la 8:08

Phép cộng làm a đổi thành 8:08, kéo theo cả dòng in và phép trừ phía sau sai. Giữ const thì g++ chặn ngay lỗi này (trích):

text
main.cpp: In member function 'Duration Duration::operator+(const Duration&) const':
main.cpp:15:17: error: assignment of member 'Duration::minutes' in read-only object
   15 |         minutes += other.minutes;
      |         ~~~~~~~~^~~~~~~~~~~~~~~~

5. Chuẩn bị cho bài kiểm tra thực hành trên lớp ​

Bài kiểm tra 15% điểm môn — lớp thứ tư 18/11, lớp thứ hai 23/11

Làm trong 60 phút, không dùng AI, không internet, chỉ được mở code các tuần trước của chính bạn. Bài đó cần một lớp có thuộc tính là đối tượng của lớp khác — thứ các tuần trước chưa dùng. Đọc kỹ mục này và tự gõ lại ví dụ trước buổi. Bài làm nén thành <MSSV>_<Ho ten khong dau>.zip và nộp lên Moodle ngay trong buổi.

Ví dụ dưới đây lập lịch phát cho một danh sách bản ghi. Slot là một khung phát: giờ bắt đầu truyền vào, còn giờ kết thúc tính ra từ bản ghi mà nó giữ.

cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

class Duration {
private:
    int minutes, seconds;

public:
    Duration(int m, int s) : minutes(m), seconds(s) {
        minutes += seconds / 60;
        seconds %= 60;
    }

    Duration operator+(const Duration& other) const {
        return Duration(minutes + other.minutes, seconds + other.seconds);
    }

    friend ostream& operator<<(ostream& os, const Duration& d);
};

ostream& operator<<(ostream& os, const Duration& d) {
    os << d.minutes << ':';
    if (d.seconds < 10) os << '0';
    os << d.seconds;
    return os;
}

class Track {
protected:
    string title;
    Duration length;                     // mot doi tuong Duration nam ngay trong Track

public:
    Track(const string& title, const Duration& length) : title(title), length(length) {}
    virtual ~Track() {}

    string getTitle() const { return title; }
    virtual Duration airTime() const { return length; }      // thoi gian chiem tren song
};

class Song : public Track {
public:
    Song(const string& title, const Duration& length) : Track(title, length) {}
    Duration airTime() const override { return length + Duration(0, 5); }     // nghi 5 giay
};

class Podcast : public Track {
public:
    Podcast(const string& title, const Duration& length) : Track(title, length) {}
    Duration airTime() const override { return length + Duration(0, 30); }    // 30 giay quang cao
};

class Slot {                             // mot khung phat trong lich
private:
    string slotNo;
    Track* track;
    Duration start;
    Duration end;                        // khong truyen vao: tinh tu start va track

public:
    Slot(const string& slotNo, Track* track, const Duration& from)
        : slotNo(slotNo), track(track), start(from),
          end(start + track->airTime()) {}     // start o day la THUOC TINH vua khoi tao ngay tren

    Duration getEnd() const { return end; }

    void print() const {
        cout << "  " << slotNo << " | " << track->getTitle() << " | " << start << " - " << end << endl;
    }
};

int main() {
    vector<Track*> playlist;
    playlist.push_back(new Song("Hello Viet Nam", Duration(4, 23)));
    playlist.push_back(new Podcast("Chuyen lap trinh", Duration(12, 0)));
    playlist.push_back(new Song("Mua he", Duration(3, 35)));
    cout << "Danh sach co " << playlist.size() << " ban ghi" << endl;

    vector<Slot> schedule;
    Duration now(0, 0);
    for (Track* t : playlist) {
        Slot s("K" + to_string(schedule.size() + 1), t, now);
        schedule.push_back(s);
        now = s.getEnd();
    }

    cout << "--- LICH PHAT ---" << endl;
    for (const Slot& s : schedule)
        s.print();

    for (Track* t : playlist)
        delete t;                        // vector chi giu con tro, khong tu delete ban ghi
    return 0;
}
text
Danh sach co 3 ban ghi
--- LICH PHAT ---
  K1 | Hello Viet Nam | 0:00 - 4:28
  K2 | Chuyen lap trinh | 4:28 - 16:58
  K3 | Mua he | 16:58 - 20:38

std::vector. Cần #include <vector>.

  • vector<Track*> playlist; là một mảng tự giãn: push_back thêm vào cuối, size() cho số phần tử, không cần tự new[] hay delete[] như Library tuần 5.
  • for (Track* t : playlist) duyệt lần lượt từng phần tử.
  • Vector chỉ lo chỗ chứa con trỏ. Đối tượng tạo bằng new vẫn phải tự delete, nên cuối main có vòng lặp delete t.
  • vector<Slot> schedule chứa thẳng đối tượng: push_back(s) chép s vào vector. Duyệt bằng for (const Slot& s : schedule) để khỏi chép thêm lần nữa.

Thuộc tính là đối tượng của lớp khác. Track có thuộc tính Duration length; Slot có Duration start và Duration end. Thuộc tính đó khởi tạo trong danh sách khởi tạo như mọi thuộc tính khác, và có thể tính từ các thuộc tính đứng trước nó: end(start + track->airTime()). Ở đây start là thuộc tính vừa khởi tạo ngay dòng trên (tham số tên là from), còn track là tham số. airTime() là hàm ảo, nên Slot không cần biết mình đang giữ bài hát hay podcast.

Thứ tự khởi tạo là thứ tự khai báo. Thuộc tính được khởi tạo theo thứ tự khai báo trong lớp, không theo thứ tự viết trong danh sách khởi tạo. Khai báo end trước start thì end(start + ...) dùng start khi nó chưa có giá trị. g++ cảnh báo:

text
main.cpp: In constructor 'Slot::Slot(const std::string&, Track*, const Duration&)':
main.cpp:60:14: warning: 'Slot::start' will be initialized after [-Wreorder]
   60 |     Duration start;
      |              ^~~~~
main.cpp:59:14: warning:   'Duration Slot::end' [-Wreorder]
   59 |     Duration end;                        // khong truyen vao: tinh tu start va track
      |              ^~~
main.cpp:63:5: warning:   when initialized here [-Wreorder]
   63 |     Slot(const string& slotNo, Track* track, const Duration& from)
      |     ^~~~
main.cpp:65:15: warning: member 'Slot::start' is used uninitialized [-Wuninitialized]
   65 |           end(start + track->airTime()) {}     // start o day la THUOC TINH vua khoi tao ngay tren
      |               ^~~~~

Chạy thì giờ kết thúc sai hết, vì lúc tính end, thuộc tính start chưa có giá trị. Cảnh báo cuối cùng ở trên nói đúng điều đó: member 'Slot::start' is used uninitialized.

  K2 | Chuyen lap trinh | 84:28 - 12:30
  K3 | Mua he | 12:30 - 88:08

Thấy cảnh báo -Wreorder thì sửa ngay thứ tự khai báo cho khớp thứ tự khởi tạo. Tính từ tham số thay vì thuộc tính, như end(from + track->airTime()), thì thứ tự khai báo không còn ảnh hưởng.

Bài 7.1 — Sửa lỗi của tuần trước bằng một từ khóa ​

Nhiệm vụ:

  1. Trong Document.h, thêm virtual trước display().
  2. Ở Book và Magazine, thêm override vào cuối khai báo display():
    cpp
    void display() const override;
    override không bắt buộc về cú pháp, nhưng nếu bạn gõ sai tên hàm hoặc sai tham số, trình biên dịch sẽ báo lỗi ngay thay vì im lặng tạo ra một hàm mới. Luôn dùng nó.
  3. Chạy lại đoạn code của bài 6.3. Bây giờ nó phải in [SACH] ....
  4. Tạo mảng Document* ds[3] chứa một Book, một Magazine, một Document thường, duyệt và gọi display().
Hướng dẫn từng bước — mở khi đã tự thử mà vẫn bí

Bước 1. Chép thư mục <MSSV>_w06 thành <MSSV>_w07, tải khung bài làm tuần 7 và chép bốn file trong đó vào thư mục mới, đè lên main.cpp và nhan_xet.txt cũ. Biên dịch g++ -std=c++17 -Wall *.cpp -o main.exe: chưa in gì nhưng phải qua.

Bước 2. Trong Document.h, thêm virtual trước void display() const;. Trong Book.h và Magazine.h, thêm override sau chữ const của display(). Chỉ sửa file .h (mục 1).

Bước 3. Làm TODO 1 trong main.cpp: Document* ds[3];, tạo ba phần tử bằng new với dữ liệu lấy từ kết quả mong đợi, rồi duyệt gọi ds[i]->display(). Biên dịch, so bốn dòng đầu.

Nếu cả ba dòng đều in [TL] ...: display() trong Document.h chưa có virtual, và lớp con cũng chưa có override để g++ nhắc (mục 1, mục 2).

Nếu gặp marked 'override', but does not override: lớp cha chưa có virtual, hoặc dòng khai báo ở lớp con lệch chữ ký với lớp cha, thường là thiếu const (mục 2). Một lần biên dịch thật khi quên virtual ở Document.h (trích):

text

Book.h:17:10: error: 'void Book::display() const' marked 'override', but does not override
   17 |     void display() const override;
      |          ^~~~~~~

Bài 7.2 — Hạn mượn theo từng loại ​

Thêm vào Document: virtual int loanDays() const; trả về 7. Ghi đè ở lớp con: Sách 14 ngày, Tạp chí 3 ngày.

Cùng một lời gọi ds[i]->loanDays(), ba kết quả khác nhau — đó là đa hình.

Hướng dẫn từng bước — mở khi đã tự thử mà vẫn bí

Bước 1. Document.h: virtual int loanDays() const;. Document.cpp: trả về 7.

Bước 2. Book trả 14, Magazine trả 3; khai báo ở .h có override.

Bước 3. Phần in hạn trả cần LoanDate của Bài 7.3. Trong lúc chờ, tạm in ds[i]->loanDays() để thấy ba số 14, 3, 7.

Nếu cả ba hạn trả đều là 7 ngày: loanDays() trong Document.h chưa virtual, và lớp con không có override để g++ báo lỗi. Một lần chạy thật:

Bài 7.3 — Lớp LoanDate và nạp chồng toán tử ​

Nhiệm vụ:

  1. Hàm phụ private: isLeap(y), daysInMonth(m, y), nextDay(). nextDay() tiến một ngày và tự xử lý sang tháng, sang năm. Năm nhuận là năm chia hết cho 4 nhưng không chia hết cho 100, hoặc chia hết cho 400; tháng 2 năm nhuận có 29 ngày.
  2. operator+(int days) — trả về một đối tượng mới, không sửa đối tượng gốc. Cách đơn giản và chắc chắn đúng: sao chép rồi gọi nextDay() đủ days lần.
  3. operator-(const LoanDate& other) — trả về số ngày giữa hai mốc.
  4. operator<< phải là friend và in dạng dd/mm/yyyy (có số 0 ở đầu khi cần). Trả về ostream& để còn nối tiếp được cout << a << b.

Dùng ngay: với mỗi tài liệu, in ngày mượn và hạn trả = today + ds[i]->loanDays().

Hướng dẫn từng bước — mở khi đã tự thử mà vẫn bí

Bước 1. Viết LoanDate.h theo sơ đồ; khung đã ghi sẵn từng TODO. operator<< khai báo trong lớp với chữ friend: friend std::ostream& operator<<(std::ostream& os, const LoanDate& d);.

Bước 2. isLeap và daysInMonth: dùng một mảng 12 số ngày; tháng 2 của năm nhuận có 29 ngày.

Bước 3. nextDay(): tăng day; vượt số ngày của tháng thì day về 1 và tăng month; month vượt 12 thì về 1 và tăng year.

Bước 4. operator+: khác Duration ở mục 4 là không cộng thẳng được. Chép *this vào một biến tạm, gọi nextDay() trên biến tạm đủ days lần, rồi trả biến tạm. Hàm có const.

Bước 5. operator-: chép mốc sớm hơn ra một biến tạm, đếm xem phải gọi nextDay() bao nhiêu lần thì biến tạm trùng ngày, tháng, năm với mốc muộn hơn.

Bước 6. Định nghĩa operator<< trong LoanDate.cpp không có LoanDate:: phía trước và không lặp lại chữ friend. In thêm 0 khi ngày hoặc tháng nhỏ hơn 10, cuối cùng return os; (mục 4).

Bước 7. Làm TODO 2 và TODO 3 trong main.cpp, so các dòng của phần 7.2 và 7.3.

Nếu hạn trả in ra 42/12/2026: nextDay() chưa sang tháng. Phép trừ cũng sai theo, vì mốc đang đếm không bao giờ trùng được ngày trả. Đáp án có chặn vòng lặp ở 100000 bước nên dừng ở 100001; không có chặn thì chương trình treo:

text

Vat ly Ngay nay: muon 28/12/2026, han tra 31/12/2026 (3 ngay)
Bao cao thuong nien: muon 28/12/2026, han tra 35/12/2026 (7 ngay)
--- 7.3 NAP CHONG TOAN TU ---

Nếu ngày mượn trôi dần theo từng dòng như dưới đây: operator+ đang sửa chính today thay vì trả về đối tượng mới (mục 4):

text
Lap trinh huong doi tuong: muon 11/01/2027, han tra 11/01/2027 (14 ngay)
Vat ly Ngay nay: muon 14/01/2027, han tra 14/01/2027 (3 ngay)
Bao cao thuong nien: muon 21/01/2027, han tra 21/01/2027 (7 ngay)

Nếu gặp must have exactly one argument ở dòng khai báo operator<<: thiếu chữ friend (mục 4).

Nếu gặp invalid operands of types 'void' and 'const char [11]' to binary 'operator<<': operator<< đang trả void thay vì ostream& (mục 4).

Thêm virtual cho maxBorrow() và display() của Reader, override ở hai lớp con. Duyệt mảng Reader* và gọi display().

Hướng dẫn từng bước — mở khi đã tự thử mà vẫn bí

Bước 1. Trong Reader.h: virtual trước maxBorrow() và display(). Reader giờ có hàm ảo nên cũng cần destructor ảo, thân rỗng là đủ: virtual ~Reader() {} (mục 3).

Bước 2. Trong StudentReader.h và GradReader.h: thêm override cho cả maxBorrow() lẫn display().

Bước 3. Làm TODO 4: Reader* rs[3] tạo bằng new, duyệt gọi display(), so ba dòng của phần 7.4.

Bài 7.5 — Destructor ảo ​

  1. Thêm vào Document: virtual ~Document(); — thân hàm in (huy Document <id>).
  2. Thêm vào Book: ~Book() override; — in (huy Book <id>).
  3. delete các con trỏ và quan sát thứ tự in.
  4. Thử nghiệm bắt buộc: bỏ chữ virtual ở destructor của Document và chữ override ở destructor của Book (bỏ mỗi virtual thì g++ báo 'Book::~Book()' marked 'override', but does not override), chạy lại, ghi lại kết quả vào nhan_xet.txt, rồi trả cả hai về chỗ cũ. Bạn sẽ thấy destructor của Book không chạy → rò rỉ bộ nhớ.
Hướng dẫn từng bước — mở khi đã tự thử mà vẫn bí

Bước 1. Document.h: virtual ~Document();. Document.cpp: thân destructor in dòng (huy Document <id>) đúng như kết quả mong đợi, có hai dấu cách ở đầu.

Bước 2. Book.h: ~Book() override;. Book.cpp: in dòng (huy Book <id>).

Bước 3. Làm TODO 5: in dòng tiêu đề, delete ba tài liệu rồi ba bạn đọc. So bốn dòng cuối: (huy Book S001) phải đứng trước (huy Document S001) (mục 3).

Bước 4. Thử nghiệm bắt buộc: bỏ virtual ở ~Document và override ở ~Book. Bỏ mỗi virtual thì chưa chạy được (trích):

text
In file included from Book.cpp:1:
Book.h:20:5: error: 'Book::~Book()' marked 'override', but does not override
   20 |     ~Book() override;      // chay TRUOC destructor cua Document
      |     ^

Bỏ cả hai thì biên dịch được, kèm cảnh báo -Wdelete-non-virtual-dtor. Cảnh báo có thể hiện ở cả Library.cpp, vì destructor của Library cũng delete qua Document*. Chép nguyên văn cảnh báo và phần 7.5 in ra vào nhan_xet.txt, trả lời ba câu hỏi trong file, rồi trả virtual và override về chỗ cũ.

Bài về nhà — phần duy nhất phải nộp ​

Viết thêm cho LoanDate hai hàm so sánh hai mốc ngày, rồi dùng chúng để viết hàm tự do bool quaHan(const LoanDate& hanTra, const LoanDate& homNay).

Hợp đồng — máy chấm bám đúng ba chữ ký này ​

cpp
bool sameDay(const LoanDate& other) const;    // ham thanh vien: hai moc co trung ngay khong
bool isBefore(const LoanDate& other) const;   // ham thanh vien: moc nay co truoc moc kia khong
bool quaHan(const LoanDate& hanTra, const LoanDate& homNay);   // ham tu do

Quy ước: đúng ngày hạn thì chưa quá hạn, nên quaHan chỉ đúng khi hanTra nằm trước homNay, không phải trước hoặc trùng.

Chữ const ở cuối không được thiếu. Máy chấm so sánh qua tham chiếu hằng const LoanDate&, nên cả sameDay lẫn isBefore đều phải có const ở cuối. Thiếu một chữ là không biên dịch được, 0 điểm — đúng cái bẫy đã gặp ở bài về nhà tuần 4 và tuần 6.

Ba hàm trên là hàm thường, không phải toán tử. Bài 7.3 trên lớp vẫn luyện operator+, operator- và operator<<, vì đó là chỗ để hiểu cách nạp chồng hoạt động. Còn bài nộp lấy điểm thì chỉ cần hàm có tên: tên hàm nói rõ nó làm gì, và người đọc code không phải đoán a < b nghĩa là gì. Máy chấm không gọi tới ba toán tử của bài 7.3.

Nghĩa là ai chưa làm xong bài 7.3 vẫn làm được trọn 10 điểm bài này. Nộp nguyên tệp LoanDate của mình cũng được, mà dùng đúng hai tệp khung mở sẵn trên Moodle rồi viết ba hàm trên cũng được.
