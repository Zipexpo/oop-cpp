Lý thuyết cần nắm ​

Tuần này mọi chỗ báo lỗi bằng cout đổi thành ném ngoại lệ, và việc xử lý dồn về main. Ví dụ vẫn ở chuyện âm nhạc: Song từ chối thời lượng âm, và một cửa hàng đĩa nhạc gặp ba loại lỗi khi bán. Mọi đoạn code đều đã biên dịch và chạy thật, và chia .h / .cpp đúng như bài thực hành bắt làm.

Về việc chia .h và .cpp. Nhiều bạn phản ánh là trang lý thuyết gom cả lớp vào một đoạn code, trong khi bài thực hành lại bắt tách ra — đúng là lệch, và từ nay trang lý thuyết chia đúng như khi bạn làm bài. Cách chia nằm ở mục 5 của trang tuần 4.

1. throw, try, catch ​

cpp
#ifndef SONG_H
#define SONG_H

#include <string>

class Song {
private:
    std::string title;
    int seconds;

public:
    Song(const std::string& title, int seconds);
    void setSeconds(int newSeconds);     // nem invalid_argument neu thoi luong <= 0
};

#endif
cpp
#include "Song.h"
#include <iostream>
#include <stdexcept>
using namespace std;

Song::Song(const string& title, int seconds) : title(title), seconds(seconds) {}

void Song::setSeconds(int newSeconds) {
    if (newSeconds <= 0)
        throw invalid_argument("Thoi luong phai duong: " + to_string(newSeconds));
    seconds = newSeconds;
    cout << "  Da doi thoi luong " << title << " thanh " << seconds << " giay" << endl;
}
cpp
#include "Song.h"
#include <iostream>
#include <stdexcept>
using namespace std;

int main() {
    Song s("Hello Viet Nam", 263);
    try {
        s.setSeconds(300);
        s.setSeconds(-50);               // nem ra: cac dong sau trong try khong chay
        s.setSeconds(200);
        cout << "  Dong nay khong bao gio in" << endl;
    } catch (const invalid_argument& e) {
        cout << "  [Du lieu sai] " << e.what() << endl;
    }
    cout << "Chuong trinh chay tiep sau catch." << endl;
    return 0;
}
text
  Da doi thoi luong Hello Viet Nam thanh 300 giay
  [Du lieu sai] Thoi luong phai duong: -50
Chuong trinh chay tiep sau catch.
  • throw invalid_argument("...") ném ra một đối tượng ngoại lệ mang theo chuỗi mô tả. Hàm dừng ngay tại đó, không cần return.
  • Trong try, gặp ngoại lệ thì các dòng còn lại của try bị bỏ qua: setSeconds(200) và dòng Dong nay khong bao gio in không chạy.
  • catch bắt đúng loại ngoại lệ; e.what() trả lại chuỗi mô tả. Sau catch, chương trình chạy tiếp bình thường.
  • Các ngoại lệ chuẩn nằm trong #include <stdexcept>.

Không ai bắt thì sao? Bỏ try và catch, chỉ còn:

cpp
    s.setSeconds(300);
    s.setSeconds(-50);                   // khong co try: khong ai bat

Chương trình in được đúng một dòng rồi dừng:

text
  Da doi thoi luong Hello Viet Nam thanh 300 giay

và thông báo sau hiện ra ở terminal (đây là thông báo của hệ thống, không phải dòng do chương trình in):

text
terminate called after throwing an instance of 'std::invalid_argument'
  what():  Thoi luong phai duong: -50

Dòng Chuong trinh chay tiep sau catch. không bao giờ được in.

2. Nơi phát hiện lỗi và nơi xử lý lỗi ​

Cửa hàng dưới đây có ba chỗ phát hiện lỗi: Album::sell(), Store::get(), checkLimit(). Không chỗ nào tự in thông báo, chỉ ném ra. main là nơi duy nhất quyết định in gì.

SoldOut chỉ có một constructor viết gọn trong lớp nên không cần file .cpp — giống Renewable.h của tuần 9. checkLimit là hàm tự do, để luôn trong main.cpp:

cpp
#ifndef SOLDOUT_H
#define SOLDOUT_H

#include <stdexcept>
#include <string>

// Ngoai le rieng cua cua hang. Chi co constructor mot dong nen khong can file .cpp.
class SoldOut : public std::runtime_error {
public:
    explicit SoldOut(const std::string& name)
        : std::runtime_error("Het dia: " + name) {}
};

#endif
cpp
#ifndef ALBUM_H
#define ALBUM_H

#include <string>

class Album {
private:
    std::string name;
    int stock;

public:
    Album(const std::string& name, int stock);

    std::string getName() const;
    void sell();                         // phat hien loi thi NEM, khong tu in
};

#endif
cpp
#include "Album.h"
#include "SoldOut.h"
using namespace std;

Album::Album(const string& name, int stock) : name(name), stock(stock) {}

string Album::getName() const { return name; }

void Album::sell() {
    if (stock <= 0)
        throw SoldOut(name);
    stock--;
}
cpp
#ifndef STORE_H
#define STORE_H

#include <string>
#include <vector>
#include "Album.h"

class Store {
private:
    std::vector<Album*> albums;

public:
    ~Store();

    void add(Album* a);
    Album& get(const std::string& name) const;   // nem out_of_range neu khong co
};

#endif
cpp
#include "Store.h"
#include <stdexcept>
using namespace std;

Store::~Store() {
    for (Album* a : albums)
        delete a;
}

void Store::add(Album* a) { albums.push_back(a); }

Album& Store::get(const string& name) const {
    for (Album* a : albums)
        if (a->getName() == name)
            return *a;
    throw out_of_range("Khong ban album " + name);
}
cpp
#include "Store.h"
#include "SoldOut.h"
#include <iostream>
#include <stdexcept>
using namespace std;

void checkLimit(int bought) {                   // moi khach mua toi da 2 dia
    if (bought >= 2)
        throw overflow_error("Moi khach chi mua toi da 2 dia");
}

int main() {
    Store store;
    store.add(new Album("Mua xuan tren thanh pho", 1));
    store.add(new Album("Hello Viet Nam", 5));

    const char* gio[] = {"Mua xuan tren thanh pho", "Mua xuan tren thanh pho", "Dia la",
                         "Hello Viet Nam", "Hello Viet Nam"};
    int bought = 0;

    for (const char* ten : gio) {
        cout << "  Mua " << ten << ": ";
        try {
            checkLimit(bought);                 // 1. con duoc mua nua khong?
            Album& a = store.get(ten);          // 2. cua hang co album nay khong?
            a.sell();                           // 3. con dia khong?
            bought++;
            cout << "OK" << endl;
        }
        catch (const SoldOut& e)        { cout << "[Het hang] " << e.what() << endl; }
        catch (const out_of_range& e)   { cout << "[Khong co] " << e.what() << endl; }
        catch (const overflow_error& e) { cout << "[Gioi han] " << e.what() << endl; }
        catch (const exception& e)      { cout << "[Loi khac] " << e.what() << endl; }
    }
    cout << "Da mua " << bought << " dia. Chuong trinh ket thuc binh thuong." << endl;
    return 0;
}

3. Tự định nghĩa ngoại lệ ​

SoldOut kế thừa runtime_error. Constructor chỉ việc ghép chuỗi mô tả rồi chuyển lên lớp cha, còn what() có sẵn, không phải tự viết. explicit trước constructor một tham số để C++ không tự đổi một chuỗi thành SoldOut.

Quên chữ public thì kế thừa thành riêng tư, và bên ngoài không gọi được what() nữa (trích):

4. Thứ tự catch và cây kế thừa ngoại lệ ​

Các ngoại lệ chuẩn và SoldOut cùng nằm trên một cây kế thừa, gốc là exception:

  • Các nhánh catch được thử từ trên xuống. Nhánh đầu tiên khớp thì chạy, các nhánh sau bị bỏ qua.
  • catch (const exception& e) khớp mọi ngoại lệ trên cây, vì tất cả đều kế thừa exception. Vì vậy nó phải đứng cuối cùng, làm lưới an toàn cho những lỗi chưa lường trước.
  • Luật: nhánh cụ thể trước, nhánh tổng quát sau.

5. Bắt bằng tham chiếu const& ​

Viết catch (exception e) thay cho catch (const invalid_argument& e) ở mục 1 thì g++ cảnh báo:

text
main.cpp: In function 'int main()':
main.cpp:13:24: warning: catching polymorphic type 'class std::exception' by value [-Wcatch-value=]
   13 |     } catch (exception e) {
      |                        ^
text
  Da doi thoi luong Hello Viet Nam thanh 300 giay
  [Du lieu sai] std::exception
Chuong trinh chay tiep sau catch.

Bắt theo giá trị thì đối tượng ngoại lệ bị chép và cắt chỉ còn phần exception, mất luôn mô tả; what() chỉ còn trả std::exception. Luôn viết catch (const LoaiNgoaiLe& e).

6. Đọc file văn bản từng dòng (cho bài về nhà) ​

Bài về nhà tuần này nạp danh mục từ file. Ví dụ dưới đây đọc một danh sách bài hát, mỗi dòng dạng ten|phut|giay. File playlist.txt đặt cùng thư mục với main.exe.

Ví dụ này không có lớp nào, chỉ có ba hàm tự do — và .h vẫn dùng được: file .h khai báo cả hàm tự do, không riêng gì lớp. Đó đúng là cách bài về nhà tuần 7 khai báo quaHan trong LoanDate.h:

text
Hello Viet Nam|4|23
Mua he|3|35
Bai loi|ba|10
Thieu truong|2
Song am|5|02
cpp
#ifndef DOCFILE_H
#define DOCFILE_H

#include <string>
#include <vector>

// File .h cung dung de khai bao HAM TU DO, khong chi lop.
std::vector<std::string> tach(const std::string& dong, char dau);
int docSo(const std::string& o);                 // nem invalid_argument neu khong phai so
void docDanhSach(const std::string& tenFile);    // nem runtime_error neu khong mo duoc file

#endif
cpp
#include "docFile.h"
#include <fstream>
#include <iostream>
#include <sstream>
#include <stdexcept>
using namespace std;

vector<string> tach(const string& dong, char dau) {        // "a|b|c" -> {"a", "b", "c"}
    vector<string> phan;
    stringstream ss(dong);
    string o;
    while (getline(ss, o, dau))
        phan.push_back(o);
    return phan;
}

int docSo(const string& o) {                               // "23" -> 23, "ba" -> nem invalid_argument
    size_t dung = 0;
    int so = 0;
    try {
        so = stoi(o, &dung);                               // dung = so ky tu stoi doc duoc
    } catch (const exception&) {                           // stoi nem loi voi chuoi khong co chu so
        throw invalid_argument("khong phai so: " + o);
    }
    if (dung != o.size())                                  // "4a": doc duoc 4 nhung con thua chu
        throw invalid_argument("khong phai so: " + o);
    return so;
}

void docDanhSach(const string& tenFile) {
    ifstream f(tenFile);
    if (!f)
        throw runtime_error("Khong mo duoc file " + tenFile);

    string dong;
    int soDong = 0, soLoi = 0;
    while (getline(f, dong)) {                             // moi vong mot dong, het file thi dung
        soDong++;
        try {
            vector<string> o = tach(dong, '|');
            if (o.size() != 3)
                throw invalid_argument("can 3 truong");
            int giay = docSo(o[1]) * 60 + docSo(o[2]);
            cout << "  " << o[0] << ": " << giay << " giay" << endl;
        } catch (const invalid_argument& e) {              // dong hong: bao, bo qua, doc tiep
            soLoi++;
            cout << "  ! Dong " << soDong << " sai dinh dang (" << e.what() << "): " << dong << endl;
        }
    }
    cout << "Da doc " << soDong << " dong, " << soLoi << " dong loi." << endl;
}
cpp
#include "docFile.h"
#include <iostream>
#include <stdexcept>
using namespace std;

int main() {
    try {
        docDanhSach("playlist.txt");
        docDanhSach("khong_co.txt");
    } catch (const runtime_error& e) {
        cout << "[Loi] " << e.what() << endl;
    }
    cout << "Chuong trinh ket thuc binh thuong." << endl;
    return 0;
}
text
  Hello Viet Nam: 263 giay
  Mua he: 215 giay
  ! Dong 3 sai dinh dang (khong phai so: ba): Bai loi|ba|10
  ! Dong 4 sai dinh dang (can 3 truong): Thieu truong|2
  Song am: 302 giay
Da doc 5 dong, 2 dong loi.
[Loi] Khong mo duoc file khong_co.txt
Chuong trinh ket thuc binh thuong.
  • ifstream f(tenFile); mở file để đọc, cần #include <fstream>. Mở không được thì !f đúng; hàm ném runtime_error để nơi gọi quyết định làm gì.
  • while (getline(f, dong)) đọc lần lượt từng dòng, hết file thì dừng.
  • Tách một dòng theo dấu |: đưa dòng vào stringstream rồi gọi getline(ss, o, '|') tới khi hết, cần #include <sstream>.
  • stoi đổi chuỗi thành số và ném ngoại lệ khi chuỗi không bắt đầu bằng chữ số. docSo bắt ngoại lệ đó rồi ném lại invalid_argument kèm mô tả rõ hơn, và kiểm tra thêm stoi đã đọc hết chuỗi chưa, để chuỗi như 4a cũng bị coi là sai.
  • try / catch nằm bên trong vòng lặp: một dòng hỏng chỉ bỏ qua đúng dòng đó, vòng lặp đọc tiếp dòng sau. Lỗi không mở được file thì ném ra ngoài, vì cả lần đọc không làm tiếp được.
  • File lưu bằng Notepad hay VS Code trên Windows, xuống dòng kiểu CRLF, cho kết quả y hệt.

Bài 10.0 — Phiếu mượn LoanSlip (20 phút) ​

Mục tiêu 20 phút20:00Chưa bắt đầu

Lớp cuối cùng của hệ thống, và là lớp đầu tiên có thuộc tính là đối tượng của lớp khác.

dueDate không truyền vào — nó được tính ngay trong danh sách khởi tạo:

cpp
dueDate(borrowDate + doc->loanDays())

Đây là chỗ bốn tuần trước gặp nhau: con trỏ lớp cha (tuần 6), hàm ảo (tuần 7), nạp chồng toán tử (tuần 7) và lớp trừu tượng (tuần 9). Phiếu không cần biết nó đang giữ sách, tạp chí, đĩa hay luận văn.

print() in đúng một dòng, thụt vào hai dấu cách:

cpp
cout << "  Phieu " << slipNo << " | " << readerName << " | " << doc->getTitle()
     << " | muon " << borrowDate << " | han tra " << dueDate << endl;

Phiếu lập ra được giữ trong vector<LoanSlip> của main — xem bài 10.4.

Mục tiêu ​

  • Phân biệt: hàm phát hiện lỗi và nơi quyết định xử lý lỗi là hai chỗ khác nhau.
  • Dùng đúng loại ngoại lệ chuẩn: invalid_argument, out_of_range, overflow_error.
  • Tự định nghĩa một ngoại lệ riêng bằng cách kế thừa std::runtime_error.
  • Viết try / catch nhiều nhánh và biết vì sao thứ tự catch quan trọng.

Vì sao phải đổi ​

Đến giờ, khi hết bản sách, Document::borrow() trả về false và Library::lend() tự in Het ban: .... Có hai vấn đề:

  1. Một lớp lo việc quản lý sách lại đang quyết định giao diện người dùng (in ra gì, tiếng gì).
  2. bool không mang theo thông tin. Mượn thất bại vì hết bản, vì sai mã, hay vì quá hạn mức — người gọi không phân biệt được.

Ngoại lệ giải quyết cả hai: nơi phát hiện chỉ việc ném ra kèm mô tả; nơi gọi quyết định làm gì.

Bài 10.1 — Ngoại lệ cho dữ liệu sai ​

Sửa các setter của Document:

cpp
void Document::setYear(int newYear) {
    if (newYear < 1900 || newYear > 2026)
        throw invalid_argument("Nam xuat ban khong hop le: " + to_string(newYear));
    year = newYear;
}

Tương tự cho setTitle với tựa đề rỗng. Nhớ #include <stdexcept>.

Chú ý: sau throw, những dòng phía dưới không chạy nữa — không cần return.

Hướng dẫn từng bước — mở khi đã tự thử mà vẫn bí

Bước 1. Chép thư mục <MSSV>_w09 thành <MSSV>_w10, tải khung bài làm tuần 10 và chép ba file trong đó vào, đè lên main.cpp và nhan_xet.txt cũ. Biên dịch g++ -std=c++17 -Wall *.cpp -o main.exe: qua, chỉ có một cảnh báo biến yeuCau chưa dùng.

Bước 2. Trong Document.cpp: thêm #include <stdexcept>, viết lại setYear như đoạn code trong đề, và setTitle tương tự: chuỗi rỗng thì ném invalid_argument kèm mô tả. Bỏ các dòng cout cảnh báo cũ.

Bước 3. Làm TODO 1 và TODO 2 trong main.cpp, so hai dòng đầu của kết quả mong đợi.

Nếu chương trình dừng với terminate called after throwing an instance of 'std::invalid_argument': lời gọi setYear(2030) đang nằm ngoài try, hoặc nhánh catch bắt sai loại (mục 1).

Bài 10.2 — Ngoại lệ riêng cho nghiệp vụ thư viện ​

Tạo file LibraryError.h:

cpp
class OutOfCopies : public std::runtime_error {
public:
    explicit OutOfCopies(const std::string& title)
        : std::runtime_error("Het ban tren ke: " + title) {}
};

Kế thừa runtime_error để dùng lại sẵn what(), không phải tự viết.

Đổi Document::borrow() từ bool thành void: còn bản thì giảm 1, hết bản thì throw OutOfCopies(title);

Hướng dẫn từng bước — mở khi đã tự thử mà vẫn bí

Bước 1. Làm TODO trong LibraryError.h: chép lớp OutOfCopies của đề vào giữa phần chốt chặn (mục 3).

Bước 2. Document.h: đổi thành void borrow();. Document.cpp: #include "LibraryError.h"; hết bản thì throw OutOfCopies(title);, còn bản thì giảm 1.

Bước 3. Library::lend() cũ dùng kết quả bool của borrow(), nên giờ không biên dịch được nữa. Bài 10.3 bỏ hàm này.

Nếu cùng một đĩa được cho mượn hai lần (hai dòng Yeu cau D001: OK): borrow() vẫn trả bool như cũ và main bỏ qua kết quả, nên hết bản mà không có gì bị ném. Lượt mượn thừa còn chiếm mất hạn mức, làm S002 bị từ chối. Một lần chạy thật:

Bài 10.3 — Không tìm thấy và vượt hạn mức ​

  1. Thêm vào Library:

    cpp
    Document& get(const std::string& id) const;   // nem out_of_range neu khong co

    Giữ lại findById (trả nullptr) cho những chỗ chỉ muốn kiểm tra. Bỏ hàm lend() cũ — việc cho mượn bây giờ do main điều phối. receive() gọi get(), nên mã sai sẽ tự ném lên.

  2. Thêm vào Reader:

    cpp
    void checkQuota(int borrowingNow) const;      // nem overflow_error neu vuot han muc
Hướng dẫn từng bước — mở khi đã tự thử mà vẫn bí

Bước 1. Library: thêm Document& get(const std::string& id) const;. Trong thân, dùng findById; nhận nullptr thì ném out_of_range với mô tả Khong co tai lieu ma <id>, còn lại trả *d. Giữ findById, bỏ lend(); receive() lấy tài liệu bằng get().

Bước 2. Reader: thêm void checkQuota(int borrowingNow) const;. Nếu borrowingNow đã bằng hoặc vượt maxBorrow() thì ném overflow_error với mô tả như dòng [Han muc] của kết quả mong đợi. maxBorrow() là hàm ảo, nên sinh viên được hạn mức 5.

Bài 10.4 — Gom xử lý về main ​

cpp
for (const char* id : yeuCau) {
    cout << "  Yeu cau " << id << ": ";
    try {
        sv.checkQuota(dangMuon);       // 1. con han muc khong?
        Document& d = lib.get(id);     // 2. co tai lieu do khong?
        d.borrow();                    // 3. con ban tren ke khong?

        dangMuon++;
        slips.push_back(LoanSlip(...));
        cout << "OK - " << d.getTitle() << endl;
    }
    catch (const OutOfCopies& e)    { cout << "[Het ban]  " << e.what() << endl; }
    catch (const out_of_range& e)   { cout << "[Khong co] " << e.what() << endl; }
    catch (const overflow_error& e) { cout << "[Han muc]  " << e.what() << endl; }
    catch (const exception& e)      { cout << "[Loi khac] " << e.what() << endl; }
}

Ba dòng trong try đọc thẳng như mô tả nghiệp vụ, không còn if lồng nhau. Một yêu cầu hỏng không làm dừng vòng lặp — các yêu cầu sau vẫn chạy.

Thử nghiệm bắt buộc. Chuyển catch (const exception& e) lên đầu tiên, biên dịch và chạy lại. Ghi vào nhan_xet.txt: chuyện gì xảy ra với ba nhánh còn lại, và vì sao. Sau đó trả về thứ tự cũ.

Danh sách yêu cầu để chạy thử (kho: S001 1 bản, S002 1 bản, TC001 4 bản, D001 1 bản, LV001 1 bản; bạn đọc là StudentReader hạn mức 5):

Hướng dẫn từng bước — mở khi đã tự thử mà vẫn bí

Bước 1. Làm TODO 3: vòng lặp theo đúng đoạn code của đề, với bốn nhánh catch theo thứ tự của đề (mục 4).

Bước 2. Làm TODO 4 tới TODO 6. Biên dịch, so đủ 20 dòng.

Bước 3. Thử nghiệm bắt buộc: chuyển catch (const exception& e) lên đầu, biên dịch, đọc kỹ cảnh báo của g++ và phần 10.2 in ra. Ghi vào nhan_xet.txt theo ba câu hỏi trong file, rồi trả lại thứ tự cũ.

Bài về nhà — không nộp, làm để ôn thi ​

Viết void Library::napTuFile(const std::string& tenFile): đọc danh mục tài liệu từ file văn bản, mỗi dòng một tài liệu; tạo đúng loại tài liệu bằng new rồi thêm vào thư viện. Cách đọc file và tách một dòng theo dấu | xem mục 6 phần lý thuyết.

Định dạng file. Các trường trên một dòng cách nhau bằng dấu |; trường đầu là loại tài liệu:

LoạiCác trường tiếp theo, đúng thứ tự
SACHmã, tựa, năm, số bản, tác giả, số trang
TAPCHImã, tựa, năm, số bản, số kỳ, tháng
DIAmã, tựa, năm, số bản, số phút
LUANVANmã, tựa, năm, số bản, giảng viên hướng dẫn, chuyên ngành

Yêu cầu:

  • File không mở được → ném runtime_error.
  • Dòng sai định dạng → bỏ qua dòng đó, in cảnh báo, tiếp tục đọc các dòng sau. Sai định dạng là: loại không có trong bảng, thiếu hoặc thừa trường, hoặc ô phải là số mà không đọc ra số.
  • Đọc xong in tổng số dòng đọc được và số dòng lỗi.

Đây là tình huống thật hay gặp nhất: một dòng hỏng không được phép làm hỏng cả lần nhập.
